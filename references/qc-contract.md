# 交付 QC 契约

## 文件级检查

- video/final.mp4 存在且大小大于 0。
- FFprobe 能读取容器、视频流、音频流、编码、画幅、帧率和时长。
- 画幅和时长符合用户目标，允许偏差必须写入报告。
- 音频不是全程静音，字幕和音频时轴覆盖合理。
- 输出目录不含密钥、Cookie、私人绝对路径或临时缓存。

## ClipForge 专项

1. compose 状态为 done。
2. gate 不为 fail；投流场景使用 --strict。
3. contact sheet 已获取并实际查看。
4. 拼接点、字幕、商品露出、转场和结尾 CTA 没有明显错误。
5. 任何 warn 都写入 qc/gate.json 和 run-report.md。
6. 修复循环不超过 3 轮。

## 真人口播专项

- 原始文件没有被覆盖。
- 删词账本有用户复核状态和时间。
- 字幕依据剪后时间重新计算。
- 字幕分屏没有孤字、遮挡、越界、重叠和明显头重脚轻。
- HTML 视觉层与字幕屏绑定，导出前已在 Studio 或等价预览中检查。
- 导出使用 dry-run 计划，最终日志保存。

## 视觉和广告专项

- 商品外观、包装、颜色和文字没有被模型改成事实之外的内容。
- 生成图不把虚构的认证、销量、功效或价格写进画面。
- 参考素材的授权、来源和署名要求已经记录。
- AI 画面、AI 配音和平台要求的 disclosure 不得被静默关闭。

## 状态值

- ready: 所有阻断检查通过，并且有 provider 或人工证据。
- preview: 只有静态计划、Prompt、脚本或 CLI help。
- blocked: 明确的运行时、凭证、成本、授权或 QC 阻塞。
- missing_evidence: 任务可能可继续，但缺 provider 输出或人工复核。
